Política de Privacidade

Esta política explica como o ReelFlow acessa e trata dados quando você conecta sua conta do YouTube para organizar e agendar vídeos.

Última atualização: 22/10/2026 Contato: lojapalaceshop.store@gmail.com

1.Quem somos

O ReelFlow é um programa para Windows que organiza filas de vídeos e os envia a um canal do YouTube pela YouTube Data API v3, a interface oficial do Google. Nesta política, “ReelFlow”, “nós” e “aplicativo” se referem ao programa e aos serviços associados a ele.

2.Dados que acessamos com a sua autorização

Quando você autoriza o acesso pela tela oficial do Google, o ReelFlow pode usar apenas os dois escopos abaixo:

  • youtube.upload: enviar os vídeos que você escolheu ao seu canal, como privados e com a data de publicação definida por você.
  • youtube.readonly: ler o nome e a imagem pública do seu canal, para exibi-los na interface.

O ReelFlow não lista nem baixa seus vídeos existentes, comentários, inscrições ou dados de receita. Também não recebe sua senha do Google: o login acontece na página oficial do Google.

3.Dados guardados no seu computador

O programa guarda alguns arquivos numa pasta oculta, %LOCALAPPDATA%\ReelFlow, dentro do seu usuário do Windows. Eles não são enviados a nenhum servidor nosso.

ArquivoO que contémPara que serve
youtube_token.jsonToken de autorização do YouTubeEvitar que você precise autorizar a cada abertura
videos_postados.jsonNome e tamanho do arquivo, ID do vídeo no YouTube, horário agendado e data do registroImpedir que o mesmo vídeo seja enviado duas vezes
licenca.datChave de licença, identificador de hardware (hash) e dados da licençaManter o programa ativado

Títulos, descrições, tags, horários e o caminho da pasta ficam só na memória enquanto o programa está aberto. A atividade exibida no log também não é salva em disco. A imagem do canal é baixada para exibição e mantida apenas na memória.

4.Dados enviados pela internet

  • Ao Google/YouTube: os vídeos e os metadados (título, descrição, tags, horário) são enviados diretamente ao YouTube pela API, de acordo com as ações que você iniciou. Eles não passam por servidores do ReelFlow.
  • Ao servidor de licenças do ReelFlow: ao ativar, e depois periodicamente enquanto o programa está aberto, o programa envia a chave de licença e um hash (um valor derivado, de sentido único) calculado a partir de identificadores do computador. O número de série original não é enviado.
  • Imagem do canal: o programa carrega a imagem pública do canal a partir do endereço fornecido pelo Google.

Este site não usa cookies de rastreamento, scripts de terceiros nem ferramentas de análise.

5.O que não fazemos

  • Não vendemos nem compartilhamos seus dados para fins comerciais.
  • Não usamos dados do YouTube para publicidade, perfis de marketing ou treinamento de modelos de IA.
  • Não coletamos sua senha do Google.
  • Não usamos automação de navegador: os envios passam pela API oficial.

Uso limitado: o uso e a transferência de informações recebidas das APIs do Google pelo ReelFlow seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6.Retenção e exclusão

Os arquivos da seção 3 permanecem no seu computador até você apagá-los. Os registros de licença no servidor são mantidos enquanto a licença estiver válida e podem ser excluídos a pedido, pelo e-mail de suporte.

Você pode apagar os dados locais removendo a pasta %LOCALAPPDATA%\ReelFlow. Para revogar o acesso ao seu canal, use as permissões da sua Conta Google.

7.Compartilhamento

Os dados são compartilhados somente com o Google, quando você envia vídeos, e com a infraestrutura de hospedagem necessária para o site e para o servidor de licenças. Não os repassamos a terceiros para outros fins.

8.Segurança

O login usa o fluxo OAuth do Google. O token fica no seu computador, dentro da pasta oculta do ReelFlow, e pode ser removido a qualquer momento. As comunicações com o site e com o servidor de licenças usam HTTPS.

9.Seus direitos

Nos termos da Lei Geral de Proteção de Dados (LGPD), você pode pedir informações sobre o tratamento dos seus dados, corrigi-los, solicitar a exclusão dos registros que mantemos e revogar a autorização. Para isso, escreva para lojapalaceshop.store@gmail.com.

10.Alterações nesta política

Podemos atualizar esta política quando o programa, a API do YouTube ou a legislação mudarem. A data no topo desta página mostra a versão em vigor.

11.Contato

Para dúvidas sobre privacidade ou sobre os dados do YouTube, escreva para lojapalaceshop.store@gmail.com.
