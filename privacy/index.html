Política de Privacidade.

Esta política explica como o ReelFlow acessa e trata dados quando você conecta sua conta do YouTube para organizar e agendar vídeos.

Última atualização: 22/10/2026Contato: suporte@reelflow.app

1. Quem somos

O ReelFlow é uma ferramenta desktop para organizar filas de vídeos e enviá-los para um canal do YouTube por meio da API oficial do YouTube Data API v3. Nesta política, “ReelFlow”, “nós” e “aplicativo” referem-se à ferramenta e aos seus serviços associados.

2. Dados que o ReelFlow acessa

Com sua autorização explícita pelo Google OAuth, o ReelFlow pode acessar:

  • dados básicos do canal associado à conta autorizada, como nome e imagem pública do canal;
  • permissão para enviar vídeos por meio do escopo youtube.upload;
  • permissão de leitura necessária para identificar o canal e exibir seu perfil por meio do escopo youtube.readonly;
  • informações locais que você escolhe fornecer, como caminhos de pastas, títulos, descrições, tags e horários de agendamento.

3. Como usamos esses dados

Usamos os dados exclusivamente para executar as funções que você solicita no ReelFlow: conectar o canal, exibir o perfil, localizar os vídeos escolhidos, enviar arquivos ao YouTube, definir metadados e acompanhar o progresso da fila.

O ReelFlow não usa os dados do YouTube para publicidade, venda de informações, criação de perfis de marketing ou treinamento de modelos. Não vendemos nem compartilhamos dados do usuário com terceiros para fins comerciais.

4. Armazenamento e segurança

O fluxo OAuth ocorre na página oficial do Google. O ReelFlow não coleta nem armazena sua senha. Após a autorização, o token é salvo localmente no computador em um arquivo chamado youtube_token.json, para evitar que você precise autorizar a cada abertura.

Arquivos de vídeo permanecem no computador do usuário até serem enviados pela API do YouTube. O ReelFlow não mantém uma cópia própria desses vídeos em um servidor.

5. Compartilhamento com o Google

Os vídeos e metadados são enviados diretamente ao YouTube por meio da YouTube Data API v3, conforme a conta e as ações autorizadas pelo usuário. O uso desses dados também está sujeito às Política de Privacidade do Google e aos Termos de Serviço do YouTube.

6. Retenção e exclusão

Você pode revogar o acesso do ReelFlow nas configurações de segurança da sua Conta Google. Também pode remover o token local apagando o arquivo youtube_token.json. Para solicitar orientação ou exclusão de qualquer dado associado ao produto, entre em contato pelo endereço abaixo.

7. Seus direitos

Você pode solicitar informações sobre o uso dos dados, revogar a autorização, corrigir informações exibidas no aplicativo ou pedir esclarecimentos sobre este documento. O ReelFlow respeita as leis de proteção de dados aplicáveis ao relacionamento com seus usuários.

8. Alterações nesta política

Podemos atualizar esta política quando o produto, a API ou os requisitos legais mudarem. A data de atualização no topo desta página será alterada quando uma nova versão for publicada.

9. Contato

Para dúvidas sobre privacidade, dados do YouTube ou exclusão de dados, escreva para suporte@reelflow.app. Antes de enviar esta página ao Google, substitua esse endereço pelo e-mail real de suporte do responsável pelo ReelFlow.
